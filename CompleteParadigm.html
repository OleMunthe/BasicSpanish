THEORY

Spanish verbs change their form depending on time. Each tense uses a specific structure built from the verb’s stem and a set of endings. Understanding these patterns makes verb conjugation much easier.

By learning the basic structures behind each tense, you can recognize and produce many verb forms even before memorizing every individual example.

1. Present Tense (Presente)

In the present tense, regular verbs are formed by removing the infinitive ending (-ar, -er, -ir) and adding present‑tense endings.

Examples:

hablar (speak)
→ habl + o / as / a / amos / an
(hablo, hablas, habla, hablamos, hablan)

comer (eat)
→ com + o / es / e / emos / en
(como, comes, come, comemos, comen)

vivir (live)
→ viv + o / es / e / emos / en
(vivo, vives, vive, vivimos, viven)

2. Past Tense – Completed Actions (Pretérito)

The preterite tense describes actions that were completed in the past. The verb stem is formed by removing the infinitive ending, and new past endings are added.

For regular -ar verbs, the basic structure is:
verb stem + é / aste / ó / amos / aron

For -er and -ir verbs, the basic structure is:
verb stem + í / iste / ió / imos / iron

Examples:

hablar (speak)
→ habl + é / aste / ó / amos / aron
(hablé, hablaste, habló, hablamos, hablaron)

comer (eat)
→ com + í / iste / ió / imos / ieron
(comí, comiste, comió, comimos, comieron)

vivir (live)
→ viv + í / iste / ió / imos / ieron
(viví, viviste, vivió, vivimos, vivieron)

3. Past Tense – Ongoing or Repeated Actions (Imperfecto)

The imperfect tense is used for ongoing actions, repeated actions, or background situations in the past. This tense has a very clear and regular structure.

For -ar verbs, the foundation of the imperfect tense is the ending -aba.

For -er and -ir verbs, the corresponding foundation is -ía.

Examples:

hablar (speak)
→ habl + aba / abas / aba / abamos / aban
(hablaba, hablabas, hablaba, hablabamos, hablaban)

comer (eat)
→ com + ía / ías / ía / íamos / ían
(comía, comías, comía, comíamos, comían)

vivir (live)
→ viv + ía / ías / ía / íamos / ían
(vivía, vivías, vivía, vivíamos, vivían)

4. Future Tense (Futuro)

In the future tense, Spanish uses a different structure. Instead of removing the infinitive ending, the endings are added directly to the entire infinitive.

infinitive + é / ás / á / emos / án

Examples:

hablar (speak) → hablar + é / ás / á / emos / án
(hablaré, hablarás, hablará, hablaremos, hablarán)

comer (eat) → comer + é / ás / á / emos / án
(comeré, comerás, comerá, comeremos, comerán)

vivir (live) → vivir + é / ás / á / emos / án
(viviré, vivirás, vivirá, viviremos, vivirán)

5. “Going to” Future (Ir + a + infinitive)

Another very common way to express future actions is to use the present tense of ir + a + infinitive.

This structure is often used for planned or intended future actions and is extremely common in everyday Spanish.

Structure:

ir (present tense) + a + infinitive

"ir" (to go) is very irregular:
voy (I go), vas (you go), va (he/she go), vamos (we go), van (they go)

Examples:

hablar (speak)
→ voy/vas/va/vamos/van + a + hablar

comer (eat)
→ voy/vas/va/vamos/van + a + comer

vivir (live)
→ voy/vas/va/vamos/van + a + vivir
